МУЗЫКАЛЬНАЯ ШКОЛА - ПЕРЕНОС И ПУБЛИКАЦИЯ

Состав проекта
1. index.html - сайт школы.
2. presentation.html - презентация учреждения.
3. gradebook.html - журнал и мониторинг успеваемости.

Быстрый запуск
Откройте index.html или gradebook.html в современном браузере.

Запуск через локальный сервер
Если на компьютере установлен Python, откройте терминал в папке проекта и выполните:

python -m http.server 8000

Затем откройте:
http://localhost:8000/
http://localhost:8000/gradebook.html

Публикация
Проект является статическим сайтом и не требует сборки. Загрузите все файлы из архива в корневую папку любого статического хостинга: GitHub Pages, Netlify, Cloudflare Pages, Firebase Hosting или обычного веб-сервера.

Перенос данных журнала
Записи журнала хранятся локально в браузере и поэтому не включаются в ZIP автоматически.

На исходном компьютере:
1. Откройте gradebook.html.
2. Нажмите "Копия данных".
3. Перенесите созданный JSON-файл вместе с ZIP-архивом.

На новом компьютере:
1. Откройте gradebook.html.
2. Нажмите "Импорт".
3. Выберите перенесенный JSON-файл.

Важно
Данные журнала остаются только в том браузере и на том адресе сайта, где они были введены. Для регулярного резервного копирования используйте кнопку "Копия данных".
